# Навык: avito-patrol

## Идея

Работать как сотрудник на перекуре: заходы по 60–80 минут с перерывами,
1–3 страницы выдачи за заход, паузы 3–8 с между действиями. Авито блокирует
быстрых (`isLogin:false`, 429/439, капчи) — неспешность здесь техника безопасности.

## Методика (проверено вручную)

### 1. Вход в выдачу
```
https://www.avito.ru/<SLUG_региона>?q=<запрос>
```
(SLUG_региона берётся из AGENTS.md → «Настройка региона».)

После загрузки включить переключатель **«Сначала из моего региона»**
(в URL появится `localPriority=1`) — отсекает иногородних.

### 2. Чтение карточек (одна страница = до 50)
Из каждой карточки `[data-marker="item"]` берём:
- название, цену, город (строки текста карточки);
- ссылку продавца: якорь `a[href*="/user/<32 hex>/profile"]`;
- якорь объявления (первая `a` с id ≥ 8 цифр).

Карточки без города с «Только доставка» = иногородние → пропуск.

Если ссылки на профиль в карточке нет — не страшно, берём на шаге 4.

### 3. Фильтр тем
Фильтр задаётся настройками AGENTS.md: `ТЕМА`, `ЗАПРОСЫ`, `ИНТЕРЕСУЕТ`,
`НЕ ИНТЕРЕСУЕТ`. Карточка подходит, если её заголовок/описание совпадают
с темой по `ЗАПРОСАМ` и не попадают в `НЕ ИНТЕРЕСУЕТ`.
Сомневаешься — не записывай.

### 4. Достаём профиль, если карточка его не дала
Зайти в объявление, подождать 3–4 с, затем:
- найти блок продавца: селектор `.js-seller-info-name` и его соседей;
- ссылка профиля — якорь `/user/{hash}/profile` рядом;
- если якоря нет — **кликнуть** по `.js-seller-info-name` (или `div._8d1c213637ecd63a`),
  подождать 3–4 с: откроется профиль `/user/.../profile` или магазин `/brands/iXXXX`.
- там же взять «На Авито с …», рейтинг, «N отзывов».

Извлечь числовой `userId` из HTML бесполезно для ссылки: в разметке он совпадает
с id аккаунта-читателя. Ссылка строится из hash-якоря, не из числа.

### 5. Дедупликация и запись
Один продавец = одна строка. Формат строки таблицы:

```
| Имя | Ссылка на профиль | Что продаёт | Цена | Рейтинг | Город |
```

Файлы: `sellers.md` (таблица) и `sellers.csv` (то же для машинной обработки).
После каждого захода — `patch` (дописать новые строки), не переписывать файл.

### 6. Дневник
В `diary.md` записывать дату, время захода, сколько страниц/объявлений прошли,
встречались ли ошибки 429/439. Если две смены подряд с ошибками — доложить
и предложить паузу на день.

## Признаки, что Авито «спалил» (реакция)
- ответы 429/439 на страницы — стоп 15+ мин;
- `isLogin:false` в разметке при залогиненном аккаунте — сессия слетела,
  доложить и остановиться (логин — только человек);
- капча — закрыть вкладку, перерыв, не решать капчи самому.

## Чего НЕ делать
- не писать продавцам и не «нажимать написать»;
- не собирать телефоны и точные адреса;
- не обходить блокировки прокси/фейками — только неспешный легальный просмотр.
