# INSTALL_PROMPT.md — установка одним промптом

Вся установка делается без ручных команд: откройте в Hermes Agent любого
профиля чат и вставьте промпт ниже. Агент сам склонирует репозиторий,
скопирует файлы, спросит регион и поставит cron-задание.

---

## Промпт (скопировать целиком в чат Гермесу)

```
Установи себе профиль «смотритель Авито» из репозитория
https://github.com/Delobot/hermes-avito-profile

Сделай по шагам:

1. Склонируй репозиторий во временную папку:
   terminal(command="git clone https://github.com/Delobot/hermes-avito-profile /tmp/hermes-avito-profile")

2. Спроси у меня (и жди ответа, не выдумывай сам):
   а) название региона для мониторинга и его slug на Авито (виден в URL выдачи);
   б) тему мониторинга и список поисковых запросов (ЗАПРОСЫ), плюс что
       ИНТЕРЕСУЕТ и что НЕ ИНТЕРЕСУЕТ — для фильтра карточек;
   в) какой вариант браузера использовать: встроенный browser_exec
      или MCP-сервер browse (расширение в моём реальном браузере).

3. Установи файлы:
   - скопируй SOUL.md из репозитория в ~/.hermes/SOUL.md
     (если он уже есть — не затирай молча: покажи diff и спроси);
   - создай рабочую папку ~/avito-patrol и скопируй туда AGENTS.md;
   - в AGENTS.md заполни блок «Настройки»: РЕГИОН, SLUG, ТЕМА, ЗАПРОСЫ,
     ИНТЕРЕСУЕТ, НЕ ИНТЕРЕСУЕТ — из моих ответов (примеры в блоке — лишь образец);
   - скопируй папку skills/avito-patrol в ~/.hermes/skills/avito-patrol;
   - в skills/avito-patrol/SKILL.md подставь мой регион и slug.

4. Настрой браузер:
   - если выбран browser_exec: включи toolset browser через hermes tools
     и сообщи, что для входа на Авито понадобится отдельный аккаунт;
   - если выбран browse: возьми блок mcpServers.browse из моего конфига OpenCode
     (спроси у меня путь к конфигу, обычно ~/.config/opencode) и добавь его
     в mcp_servers в ~/.hermes/config.yaml под именем browse, затем /reload-mcp.

5. Поставь cron-задание (через свой инструмент cronjob, action="create"):
   - schedule: "0 9 * * 1-5"
   - name: "avito-shift"
   - workdir: "~/avito-patrol"
   - skill: "avito-patrol"
   - prompt: "Рабочий день по AGENTS.md: патруль Авито по навыку avito-patrol
     (тема и запросы — из блока «Настройки» в AGENTS.md).
     Работай по графику с перекурами и обедом, в ~17:00 обнови sellers.md
     и напиши сводку за день."
   - deliver: спроси у меня, куда присылать сводку (local/telegram/discord).

6. Создай в ~/avito-patrol пустые файлы sellers.md, sellers.csv и diary.md
   с заголовками по формату из SKILL.md.

7. Прогони проверку: hermes cron list (или cronjob action="list") —
   покажи, что задание стоит, и выведи итог установки списком: что сделано,
   что осталось сделать мне вручную (вход на Авито — только человек).

Не запускай просмотр Авито прямо сейчас — только установка.
Если какой-то шаг не выходит, не молчи: покажи ошибку и предложи вариант.
```

---

## После установки останется сделать вручную (только человек)

- Войти на Авито (капча/СМС) — в браузере варианта 2B это ваш обычный браузер,
  в варианте 2A — Chromium Гермеса под одноразовым аккаунтом.

## Проверка, что всё живо

Сказать Гермесу: «проведи короткую тестовую смену по avito-patrol — одна страница
выдачи, таблицу обнови, дневник запиши» — и посмотреть ~/avito-patrol/diary.md.
