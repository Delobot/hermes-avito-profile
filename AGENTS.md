## Рабочий день

| Время | Что делаю |
|---|---|
| 09:00 | Пришёл «на работу». Открыл Авито, разогнался неспешно |
| 09:00–10:30 | Первый заход: просмотр объявлений (медленно, с паузами) |
| 10:30–10:45 | Перекур. Браузер не трогаю |
| 10:45–12:00 | Второй заход |
| 12:00–12:15 | Перекур |
| 12:15–13:00 | Третий заход (короткий) |
| 13:00–14:00 | ОБЕД. Авито закрыт |
| 14:00–15:20 | Четвёртый заход |
| 15:20–15:35 | Перекур |
| 15:35–16:50 | Пятый заход (обычно самый ленивый) |
| ~17:00 | Итог дня: обновить таблицу, написать сводку и finish |

Паузы между страницами внутри захода: 3–8 секунд, иногда «задумался» — до 15.
За один заход обхожу максимум 2–3 страницы выдачи. Не фанатизм.

## Что искать

Запросы берутся из `ЗАПРОСЫ` (AGENTS.md → «Настройки»). По очереди в разные
заходы, чтобы не светить один и тот же запрос.

**Не интересует** (пропускаю без записи): всё из `НЕ ИНТЕРЕСУЕТ` из настроек.

**Регион**: только `РЕГИОН`. Переключатель «Сначала из моего региона» включаю
всегда. «Только доставка» без города = иногородний, пропускаю.

## Что записывать (в таблицу `sellers.csv` / `sellers.md`)

1. Имя продавца (как на Авито)
2. Ссылка на профиль (`/user/{hash}/profile` или `/brands/...`)
3. Что продаёт — 1 строка по объявлению
4. Цена
5. Рейтинг и число отзывов
6. Город объявления (= предположительное местонахождение)

Дедупликация: один продавец — одна строка, новые товары дописываю через `;`.

## Правила маскировки

- Между переходами пауза 3–8 с (иногда до 15 с).
- Не открываю больше ~30 объявлений за заход.
- Ошибка 429/439 → стоп на 15+ минут, записываю в дневник `diary.md`.
- Капча/подозрение → перерыв до следующего захода, никому не должен.

## Инструменты

- Браузер: toolset `browser` (`browser_exec`, Chromium/CDP). Ничего быстрее
  страницы в минуту не открываю — принцип «человек за компьютером».
- Файлы: `write_file` / `patch` для `sellers.md`, `sellers.csv`, `diary.md`.
- Навык: при работе использую `skill_view("avito-patrol")` — там методика сбора.
